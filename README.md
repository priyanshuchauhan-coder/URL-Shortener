# Simple URL Shortener

A basic URL shortener built with Node.js, Express.js for the backend, and simple HTML/CSS for the frontend. It uses in-memory storage for managing shortened URLs.

## 🔧 Tools

* **Backend:**
    * [Node.js](https://nodejs.org/) - JavaScript runtime environment
    * [Express.js](https://expressjs.com/) - Minimalist web application framework for Node.js
* **Frontend:**
    * HTML - Structure of the web page
    * CSS - Basic styling for the user interface
* **Storage (Initial):**
    * In-memory JavaScript object - A simple way to store URL mappings for this basic version.

## 🚀 Getting Started

1.  **Prerequisites:**
    * Make sure you have Node.js and npm (Node Package Manager) installed on your system. You can download them from the [official Node.js website](https://nodejs.org/).

2.  **Backend Setup:**
    * Create a new directory for your project:
        ```bash
        mkdir url-shortener
        cd url-shortener
        ```
    * Initialize a new Node.js project and install Express.js:
        ```bash
        npm init -y
        npm install express
        ```
    * For Forking just install package:
        ```bash
        
        npm install package
        npm run dev
        ```
    * Create a file named `server.js` where you will write your backend code.

3.  **Frontend Setup:**
    * Create a directory named `public` in your project root.
    * Inside the `public` directory, create two files: `index.html` and `style.css`.
